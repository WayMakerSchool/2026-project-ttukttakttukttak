# 📡 카메라 중계 서버

책을 찍는 XIAO ESP32-S3 보드와 책 배경음악 백엔드 사이에서 **가장 최근 사진 한 장**을 들고 있는 서버예요.
백엔드(`backend/camera_book.py`)는 이 서버에 "지금 찍어"라고 말하고 사진을 받아 가요.

외부 라이브러리가 없어서 설치할 것이 없어요. Node 18 이상이면 돼요.

## 실행

```bash
cd book-bgm/camera-server
BOARD_URL=http://192.168.0.25 node server.mjs
```

`BOARD_URL`에는 보드를 켰을 때 시리얼 모니터에 나오는 주소를 넣어요.
브라우저에서 http://localhost:4000/photo 를 열면 카메라가 찍은 사진이 2초마다 새로 보여요.

백엔드는 이 서버 주소를 환경 변수로 알려 주고 실행해요.

```bash
cd book-bgm/backend
CAMERA_SERVER_URL=http://localhost:4000 uvicorn main:app --reload --port 8000
```

> `.env`에 `CAMERA_SERVER_URL`을 적는 것으로는 적용되지 않아요. 백엔드가 `.env`를 읽기 전에 이 값을 먼저 읽기 때문에, 위처럼 명령 앞에 붙여 주세요.

## 보드 펌웨어 두 가지

| 방식 | 펌웨어 | 설정 |
| :-- | :-- | :-- |
| 가져오는 방식 | [`firmware/CameraWebServer`](../firmware/CameraWebServer/) | `BOARD_URL`에 보드 주소를 넣어요. 서버가 보드의 `/capture`를 불러 사진을 가져와요. |
| 보내는 방식 | 보드가 `POST /photo`로 사진을 계속 올리는 펌웨어 | `BOARD_URL=`(빈 값)으로 실행하고, 펌웨어에는 이 컴퓨터의 주소(`http://컴퓨터IP:4000/photo`)를 넣어요. |

CameraWebServer는 켜질 때 320×240으로 시작해서 책 글자를 읽을 수 없어요.
그래서 서버가 처음 사진을 가져올 때 해상도를 1600×1200으로 올리고, 보드가 재시작돼 해상도가 돌아가면 다시 맞춰요.

보드가 사진을 올리고 있는 동안에는 서버가 가져오기를 시도하지 않아요. 그래서 `BOARD_URL`을 그대로 두고 펌웨어만 바꿔도 돼요.

## 꼭 알아둘 것

- **좌우 반전**: XIAO ESP32-S3 Sense의 카메라는 기본 설정에서 좌우가 뒤집힌(거울) 사진을 내요. 거울 사진의 글자는 AI가 읽지 못해서 엉뚱한 책으로 인식해요. 서버가 보드의 `hmirror`를 켜서 바로잡아요. 미리보기에서 글자가 거울처럼 보이면 `BOARD_HMIRROR=0`으로 바꿔 보세요.
- **오래된 사진**: 10초가 넘은 사진은 내주지 않고 오류(503)를 돌려줘요. 보드가 멈췄을 때 옛 사진으로 엉뚱한 인식이 나오는 것을 막기 위해서예요.
- **책 방향**: 책이 옆으로 누워 있어도 인식돼요. 글자가 거울처럼 뒤집힌 것만 문제가 돼요.

## 주소

| 주소 | 누가 쓰나요 | 하는 일 |
| :-- | :-- | :-- |
| `POST /capture` | 백엔드 | 지금 한 장 찍어요. |
| `GET /photo/image` | 백엔드 | 가장 최근 사진(JPEG)을 줘요. 1.5초보다 오래됐으면 새로 찍어서 주고, 10초가 넘은 사진밖에 없으면 503을 줘요. |
| `POST /photo` | 보드 | 사진을 올려요. (multipart `imageFile`) |
| `GET /photo` | 사람 | 미리보기 페이지예요. |
| `GET /status` | 사람 | 마지막 사진의 크기와 오류를 보여 줘요. |

## 환경 변수

| 이름 | 기본값 | 설명 |
| :-- | :-- | :-- |
| `PORT` | `4000` | 서버 포트 |
| `BOARD_URL` | `http://192.168.0.25` | 보드 주소. 비우면 보내는 방식만 받아요. |
| `BOARD_FRAMESIZE` | `15` | 보드 해상도 번호. Arduino-ESP32 3.3.x에서 15가 1600×1200이에요. |
| `BOARD_WIDTH` | `1600` | 기대하는 사진 가로 크기. 다르면 해상도를 다시 맞추고 경고를 남겨요. |
| `BOARD_QUALITY` | `10` | JPEG 품질. 낮을수록 고화질이에요(0~63). |
| `BOARD_HMIRROR` | `1` | 좌우 반전 바로잡기. 글자가 거울처럼 보이면 `0`으로 바꿔요. |
| `BOARD_VFLIP` | `0` | 위아래 뒤집기. |
